Foundation AI Anomaly Detection

Few-shot anomaly detection with frozen foundation visual encoders

Based on: Foundation Visual Encoders Are Secretly Few-Shot Anomaly Detectors (TU Munich)

How It Works

  • 1️⃣ Select 1–8 normal reference images
  • 2️⃣ DINOv2 ViT-B/14 extracts rich patch-level features
  • 3️⃣ A lightweight manifold projector is trained on these features
  • 4️⃣ At test time, reconstruction error reveals anomalies
No task-specific pre-training needed · Works across many defect types
